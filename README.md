A one-image summary of the world's news of Monday 23 November 2026,
drawn as a 1024×1024 PNG poster.

The poster carries 40 verified stories, each tagged with its source:
3 illustrated lead stories across the top, 12 illustrated panels below
them, and a text index covering stories 16–40. A DATE CHECK box at the
foot of the page fences off news from other days, so everything on the
poster belongs to Monday 23 November 2026.

## Running it

The entry program (`main.ts`, Node) copies the bundled poster
(`assets/poster.png`) to `entry.png` in the output directory —
`$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`. It needs no
network and produces the same bytes on every run.
